# Flutter版 更新履歴

## 2026-11-14

- 5教科の4択演習データ生成と、年度別資料の同期・分野抽出を追加
- 数学の小問集合に特化した演習データを拡張
- 基礎反復用の5教科データと誤答復習ループを分離
- Noto Sans JPのRegular / Boldをローカルアセットとして同梱するビルド処理を追加
- 教材の重要語句・公式を参考書風のカード表示に変更
- PC向け2カラム演習とキーボード操作を強化
- ホーム画面への追加案内、Web App Manifest、Service Workerを追加
- モード画面に簡易パスワード確認を追加
- URLのベースパス切り替えと深いURLへの復帰処理を整理
- 教材ライブラリの独立導線を廃止し、理科・社会の分野別要点まとめに集約
- 下積みモードの基礎問題と公立入試問題を同一演習DBに統合
- 高専・下積みモードを専用ホーム／専用ナビゲーションを持つ独立シェルに変更
- 高専モード・下積みモードごとに専用Web App Manifestとホーム画面アイコンを用意
- ホーム画面に連続学習日数と入試演習・要点まとめへのクイックアクセスを追加
- 回答後の待ち時間と起動時の装飾アニメーションを削減

※ GitHub Pagesの簡易パスワード確認は、教材データを秘匿するセキュリティ機能ではありません。
