# Study

MANABIXX が開発する独立した学習サービスを独立して再構築するプロジェクトです。

## 技術スタック
- **Svelte 5 / SvelteKit** — アプリ画面とルーティング
- **TypeScript / JavaScript** — 型付き学習ロジックと画面操作
- **HTML5 / CSS3 / Tailwind CSS 4** — レスポンシブUIとデザイン
- **Vite** — 開発・ビルド環境
- **Bits UI / Lucide Svelte** — UI部品とアイコン
- **Zod** — データ構造の検証基盤
- **Python 3** — 問題データの品質監査
- **Bash** — CIでの検証実行
- **JSON / YAML / Markdown / SVG** — 教材データ、CI設定、ドキュメント、図版
- **Service Worker / Web App Manifest** — PWA・オフライン利用

## 開発方針
- 旧Studyとは独立した設計・UI・データ構造で開発する
- 旧Studyは新Studyの完成・動作確認まで維持する
- 理科・社会を中心に問題演習を拡充する
- 5教科を扱う模試モード、教材ノート、過去問演習を段階的に実装する
- モバイル・タブレット・PCに対応し、PWAとして利用できるようにする
- 学習履歴は初期段階では端末内に保存する
- 意見送信はGitHub Issueへ直接つなぎ、Cloudflareなどの中継サーバーを使用しない
- 更新時は必ず `shitadumi/CHANGELOG.md` とサイト内リリースノートを同時に更新する

## Flutter版の統合実装（2026-11-14）

- ルートURL（/）をFlutter Web本体としてビルドし、/practice/kosen、/practice/foundation-training、/records、/summary のクリーンURLに対応。
- Service WorkerでFlutterアプリ資産とstatic/dataの全JSON教材を初回キャッシュ。データ・アプリのバージョン変更を検出して更新し、対応ブラウザーでは週次Periodic Background Syncを登録。
- 回答後は解説を表示したまま待機し、画面下の「次の問題へ」で進む操作へ変更。誤答キュー・苦手分野集計・ワンタップ復習を追加。
- 下積みモードに青藍泰斗高校・佐野松桜高校の2027年度公開情報を反映した合格マップと、JSON駆動の「君へ」メッセージを追加。
- 日次問題バッチの検証・取り込みワークフローを追加。各カテゴリで5教科各10問以上を満たす編集済みバッチのみ取り込み、重複IDの上書きを拒否。
